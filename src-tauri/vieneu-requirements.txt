# Sinh bằng chính python.exe đóng gói cùng app (Python 3.11.16, CPython cp311,
# Windows x64) — KHÔNG dùng Python hệ thống, vì tag wheel (cp311 và cp314)
# không tương thích và requirements sinh sai sẽ không cài được trên bản Python
# mà app thực sự chạy:
#
#   <models>/python/python.exe -m pip download vieneu -d <tmp> --only-binary :all:
#   <models>/python/python.exe -m pip hash <tmp>/*.whl
#
# `--only-binary :all:` bắt buộc: nếu một gói phải biên dịch từ nguồn thì kết
# quả không còn tất định. Toàn bộ 79 gói dưới đây (kể cả phụ thuộc gián tiếp)
# đều có wheel sẵn cho Windows x64 / CPython 3.11 — không gói nào phải build.
#
# Đã kiểm: không có `torch` trong tập phụ thuộc (đường CPU của VieNeu không
# cần torch — torch chỉ nằm trong extra "legacy"/"cuda"/"finetune", không kéo
# theo khi cài `vieneu` trơn). `pip install --require-hashes` với đúng file
# này đã chạy thử thành công, offline, trên máy dev.
#
# --require-hashes đòi MỌI gói phải ghim `==` kèm hash, kể cả phụ thuộc gián
# tiếp — không tự thêm/bớt gói ở đây mà không chạy lại `pip download` để lấy
# đúng tập đã giải.
